# Available Voices

This is a list of the 12 built-in voices available in **Yiperi Voice**. Each voice consists of a bank of short phonetic sound clips loaded from `Resources/Yiperi-voice/Sounds/voice_[code]`.

| Voice Code | Description |
|---|---|
| `keyb` | Not actually a voice; it consists of the soft sound effects of typing on a modern keyboard. |
| `mokito` | A tiny, buzzing voice resembling a mosquito. |
| `neni` | A high-pitched, metallic voice that sounds similar to a chipmunk. |
| `nina` | A sweet, low-pitched voice with highly clear syllable pronunciation. |
| `nomo` | A somewhat deep, metallic voice with lower clarity. |
| `np` | Based on the `nina` voice, but only includes the syllables *'pa pe pi po pu'* and *'na ne ni no nu'* to demonstrate that the engine does not require a complete phonetic database to function. |
| `radi` | A highly metallic voice evoking a radioactive environment, sounding as if spoken from inside a protective mask or helmet. |
| `retro` | A voice with band-limited frequencies to simulate the 8-bit MS-DOS PC speaker era. |
| `robo` | Intentionally robotic and metallic. |
| `wispi` | A soft, whispering voice. |
| `wiwi` | A voice with a strong tendency toward 'W' and 'U' sounds in all syllables, evoking a sweet and sad character. |
| `zobi` | A zombie or horror creature voice. |
